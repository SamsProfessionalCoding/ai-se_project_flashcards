# Flashcard App

My first project in TripleTen's AI-Assisted Software
Engineering program. It includes decks of flashcards,
each of which can be viewed in a carousel.

## Features

The application features a list of decks, each containing lessons for its subject. Opening a deck displays its cards, where users can flip cards to reveal answers or delete cards. The Practice button opens a carousel where users can switch between cards with the left and right arrow buttons and flip a card to display its answer. The new features introduced in sprint 5 are the addition of an open deck view, the (optional) routing code refactoring and also the (optional) confirmation modal, and the newly responsive design concept implementation. I Have also added box shadowing on the buttons and cards.

## Technologies used

Javascript, HTML, CSS.
